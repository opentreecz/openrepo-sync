Coverage is measured on every CI run using [cargo-tarpaulin](https://github.com/xd009642/tarpaulin) and reported to [Codecov](https://codecov.io).
An HTML report is published here automatically on every successful CI run.

|---|---|
| `models` | `PackageVersion::parse` — semver, `v`-prefix, pre-release, raw fallback; ordering; Display |

| `repo_client` | All HTTP methods via mock server: list/upload/delete/whoami, pagination, auth header, error handling |

| `sources::direct_url` | Static URL version parsing, LATEST URL download+version extraction, filename utilities |

## Running Coverage Locally

```sh
# Install tarpaulin (once)
cargo install cargo-tarpaulin

# Run with terminal output
cargo tarpaulin --out Stdout

# Run and generate HTML report
cargo tarpaulin --out Html --output-dir coverage/
open coverage/tarpaulin-report.html

# Run and generate Lcov (for editor integration)
cargo tarpaulin --out Lcov --output-dir coverage/
```

## CI Integration

Coverage runs automatically on every push and pull request as part of the `Coverage` job in
[ci.yml](https://github.com/opentreecz/openrepo-sync/blob/main/.github/workflows/ci.yml).

The job:
1. Installs `cargo-tarpaulin` via [`taiki-e/install-action`](https://github.com/taiki-e/install-action) (cached binary)
2. Runs `cargo tarpaulin` producing Cobertura XML, Lcov, and HTML output
3. Uploads results to [Codecov](https://codecov.io) (requires `CODECOV_TOKEN` secret)
4. Uploads the HTML report as a 30-day CI artifact, which is then embedded into these GitHub Pages

To enable Codecov: sign in at [codecov.io](https://codecov.io) with your GitHub account,
add the repository, and set the `CODECOV_TOKEN` repository secret in **Settings → Secrets → Actions**.
